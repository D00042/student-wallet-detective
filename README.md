# Student Wallet Detective

A soft, modern, interactive dashboard concept for exploring fictional student spending patterns.

## Features
- KPI cards for total spending, transaction count, average purchase, and top category
- Interactive filters for city, study level, and month
- Spending trend and category breakdown
- Responsive layout for desktop and mobile
- Share action and reset filters

## Data note
This web demo uses generated illustrative rows and is not connected to the PostgreSQL database or Power BI report. It is not a live representation of the underlying CSVs. Replace the demo data in `index.html` with validated project data before presenting exact findings.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment URL to appear in the Pages section. Add that public URL to your LinkedIn Featured section.
